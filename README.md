# Aurora — Agenda moderne

Un agenda moderne, élégant et fluide, inspiré de Google Agenda avec une touche premium.

## Stack technique

- **Next.js 16** (App Router)
- **React 19** + **TypeScript 5**
- **Tailwind CSS 4**
- **date-fns v4** (locale française)
- **lucide-react** (icônes)

## Fonctionnalités

- 3 vues : **Jour**, **Semaine**, **Mois**
- Création / édition / suppression d'événements
- 8 couleurs d'événements personnalisables
- Thème clair / sombre (sauvegardé)
- Persistance locale (localStorage)
- Indicateur d'heure courante (vue Jour)
- Design premium : glass-morphism, dégradés aurora, typographie Playfair Display
- PWA installable (manifest + icônes)
- Responsive mobile / desktop
- Accessibility : aria-labels, navigation clavier, focus visible

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)

## Déploiement sur Vercel

1. Pousser le code sur GitHub
2. Connecter le repo sur [vercel.com](https://vercel.com)
3. Vercel détecte automatiquement Next.js — déployer

```bash
# ou en CLI
npm i -g vercel
vercel --prod
```
